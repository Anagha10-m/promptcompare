# PromptCompare

**PromptCompare** is a free, open-source prompt experiment tracker. Save different prompt versions, paste in AI responses, rate them, and compare results side by side. It is intentionally small, private, and beginner-friendly.

> **Note:** PromptCompare does **not** call Claude, OpenAI, or any AI API. You run prompts using a service of your choice, then paste the responses into this tool. Example outputs are illustrative, not generated by live models.

## Features

- Save a prompt, model name, response, variant, rating, and notes.
- Compare any two saved runs side by side.
- Keep up to 300 runs in your browser's `localStorage`.
- Export your experiments as JSON and import them later.
- Load two illustrative example runs to explore the app.
- No account, API key, server, tracking, external dependency, or payment required.
- Responsive layout for phones and computers.

## Run it

**Option A: Open locally.** Download the project, extract the ZIP, and open `index.html` in a modern browser. Your browser may restrict storage for local files; export JSON to preserve your work.

**Option B: Publish on GitHub Pages.**

1. Create a new **public** repository on GitHub named `promptcompare` (or a different available name).
2. Upload `index.html`, `styles.css`, `logic.js`, `app.js`, `README.md`, `LICENSE`, and the `tests` folder to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then **Save**.
5. After Pages finishes deployment, follow the website link shown there.

GitHub Pages URLs usually follow `https://YOUR-USERNAME.github.io/promptcompare/`. Replace the username and repository name with your actual values. Publishing may take a few minutes.

**Privacy:** Local storage belongs to the browser/origin on that specific device. Data is not automatically synced between devices. Export before switching browsers or clearing site data. JSON exports contain your prompts and responses; treat them as sensitive if they include private information.

## How to use

1. Paste a prompt into an AI model you already use.
2. Enter an experiment name and label it `A`, `B`, or another variant.
3. Paste the response into PromptCompare, rate it, and save.
4. Change your prompt, repeat, and compare two runs.
5. Export JSON to back up your experiments.
